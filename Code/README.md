Vous trouverez ici trois dossiers contenant uniquement les fichiers réalisés pendant le stage :
- Le dossier Arduino contient les fichiers .ino permettant la lecture des données des capteurs en USB et leur envoi par différents protocoles de communication.
- Le dossier GPS contient le code à flasher dans l'Icarus v2 d'Actinius, permettant d'obtenir et de parser les trames NMEA (coordonnées GPS).
- Le dossier Qt contient tous les fichiers et images intervenus dans la conception de l'application de visualisation des données.
